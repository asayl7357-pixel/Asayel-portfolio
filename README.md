# Asayel Alzahrani — Portfolio

Static English portfolio based on the 5-page PDF provided by the user. Original wording is retained, including spelling.

## Files
- `index.html`: all five connected sections
- `style.css`: layout and responsive styling
- `script.js`: mobile navigation and project preview notices
- `assets/`: cropped visuals from the PDF and original page references

## Publish on GitHub Pages
1. Create a public GitHub repository.
2. Upload **the contents** of this ZIP to the repository root.
3. Go to Settings → Pages → Build and deployment → Deploy from a branch → main / (root) → Save.

**Important:** The original PDF did not include live URLs for Bema HR Platform or Coffee V60 UI, so their buttons currently display a notice rather than invented links. To make them open real projects, add the URLs to `script.js`.
